Generated by `scripts/build_knowledge.py` from `CHANGELOG.md`; do not edit by hand.

Exhaustive variant analysis of the intended target, replacing the saturated target-tier BLAST hit list as the source of the variant summary and inclusivity.

## Added

- Exhaustive variant analysis from every genome assembly
- Plasmid-borne targets: "region not found" split in two
- Exhaustive inclusivity explains its gap
- Variant tables describe the match in words
- Inclusivity title
- Partitioned BLAST variant source
- Regions hidden by N are reported as masked
- Oligo windows are clamped to the stored region
- History lists new oligo sequence variants
- Report states when human background was not searched

- Nucleotide-record wording and history noise

- Probe 3' end was underlined like a primer's
- Variant summary was always empty on a real run
- Stale "planned for v0.4.0" texts
- Inclusivity silently skipped years it could not sample
- Exclusivity table undercounted hits on finely-split taxa
