# Release v2.2.0

Generated by `scripts/build_knowledge.py` from `CHANGELOG.md`; do not edit by hand.

Released 2026-11-17; annotated tag `v2.2.0`.[^changelog]

The analysis after two code reviews and an independent whole-project evaluation (2026-11-17). Every record now names the code that made it (a code fingerprint and the git commit), and missing evidence no longer reads as No flags. Off-target sites are graded by the same rules as the target (R1-R9) together with the old mismatch levels; possible deletions count in the inclusivity status, which ends at the run's year; R6 grades ambiguity codes over a primer's 3'-most 16 nt and the whole probe, and MGB probes are recognised from their dye names. Also: the variant analysis counts only the records NCBI lists now and remembers its lookups, BLAST resubmission is bounded, the knowledge bundle, upload of assay files and progress bars in the GUI. **Off-target and inclusivity results change against 2.1.0: rerun an assay before comparing it with an older record.** Code fingerprint (`qpcr-assay-check fingerprint`): `b68fa8fe6c8946a15c1bc1bc7a49362b868c1484327fbb56ad9c3d9348e44455`
