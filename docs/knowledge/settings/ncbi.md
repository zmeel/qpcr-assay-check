# Defaults

Generated by `scripts/build_knowledge.py` from `default_config.yaml`; do not edit by hand.

Every value is a starting point, not an acceptance criterion: each laboratory reviews it within its own quality system. An assay file can override a value under `settings:`; a `--config` file overrides the defaults for every run.[^default-config]

```yaml
ncbi:
  # NCBI credentials are NEVER read from configuration: use the NCBI_EMAIL (required for any
  # network use) and NCBI_API_KEY (optional) environment variables.
  tool: qpcr-assay-check
  blast_url: https://blast.ncbi.nlm.nih.gov/Blast.cgi
  eutils_url: https://eutils.ncbi.nlm.nih.gov/entrez/eutils
  request_timeout_s: 120
  max_retries: 5
  backoff_base_s: 2.0              # exponential: 2, 4, 8, ... seconds (plus jitter)
  blast_min_interval_s: 10         # NCBI: contact the BLAST server at most once per 10 s
  poll_interval_s: 60              # NCBI: poll a given RID at most once per minute
  max_wait_minutes: 240            # give up waiting (the job stays resumable); a human search took 61 min
  resubmit_after_minutes: 90       # a search resumed in a later run that has been WAITING this
                                   #   long since submission is submitted anew (once per run);
                                   #   `run/search --resubmit` does so at once
  rid_lifetime_hours: 36           # NCBI keeps results for about 36 h; older jobs are resubmitted
  blast_cache_ttl_days: 7          # BLAST results are only reused within a run / a resume
  taxonomy_cache_ttl_days: 30
  cache_dir: null                  # null = per-user cache directory
  datasets_url: https://api.ncbi.nlm.nih.gov/datasets/v2   # NCBI Datasets v2 (published OpenAPI spec)
  datasets_batch_size: 20          # assemblies per genome download request (API maximum: 100)
```
