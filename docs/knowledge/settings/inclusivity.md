# Defaults

Generated by `scripts/build_knowledge.py` from `default_config.yaml`; do not edit by hand.

Every value is a starting point, not an acceptance criterion: each laboratory reviews it within its own quality system. An assay file can override a value under `settings:`; a `--config` file overrides the defaults for every run.[^default-config]

```yaml
inclusivity:
  # How well the oligos still match the intended target, over time: built from the exhaustive
  # variant analysis (every genome of the target), bucketed by release year. ALL of these are
  # starting points, not acceptance criteria.
  lookback_years: 10               # how many years back from today to report (0 records is a
                                    # valid, honestly-reported answer for an early year, not skipped)
  warn_below_percent: 95           # % of genomes detected (0-1 mismatch, no 3' mismatch)
  fail_below_percent: 80           # below this, WARN/FAIL: applied to the whole-fragment genome
                                    # outcome over the verdict window below
  verdict_window_years: 3          # exhaustive: the last N complete release years + this year
  min_genomes_for_verdict: 100     # fewer genomes with the region in the window: INCOMPLETE
  min_genomes_per_year: 30         # a single year with at least this many genomes below
                                    # fail_below_percent inside the window gives WARN when the
                                    # pooled figure passes ("release year <year> on its own");
                                    # smaller years are marked "few records" and only shown
  max_undetermined_percent: 25     # more undetermined genomes than this share of those with the
                                    # region (whole fragment over the window; a channel over all
                                    # genomes): INCOMPLETE, not a percentage status. The report
                                    # also gives the figure if all undetermined were escapes and
                                    # if all were detected. Your laboratory's choice.
  status_axis: release             # which year groups the genomes for the status window:
                                    # release (NCBI release year) or collection (the year the
                                    # sample was collected, as its submitter recorded it). The
                                    # other axis is shown as information; with collection,
                                    # genomes without a usable date are left out and counted.
```
