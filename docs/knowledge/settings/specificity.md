# Defaults

Generated by `scripts/build_knowledge.py` from `default_config.yaml`; do not edit by hand.

Every value is a starting point, not an acceptance criterion: each laboratory reviews it within its own quality system. An assay file can override a value under `settings:`; a `--config` file overrides the defaults for every run.[^default-config]

```yaml
specificity:
  # Assessment of BLAST hits: full-length re-alignment, site classification, amplicon pairing.
  # ALL of these are starting points, not acceptance criteria: review them for your laboratory.
  off_target_tiers: [near_neighbours, background, exclusivity]  # off-target by construction
  max_sites_per_query: 2000        # strongest hits first; beyond this the assessment is INCOMPLETE
  window_padding_nt: 10            # subject bases fetched beyond a partial hit, to allow gaps
  max_amplicon_size: 2000          # predicted products longer than this are ignored
  max_amplicons: 500               # safety cap for repetitive regions
  report_top_sites: 25             # alignments shown in the HTML report
  alignment: {match: 1, mismatch: -3, gap_open: 5, gap_extend: 2}
  # A primer site is CRITICAL when it has at most this many mismatches AND gaps and this many
  # clean (perfectly matching) nucleotides at the 3' end; WARNING with the looser limits.
  primer_site:
    critical: {max_mismatches: 3, max_gaps: 0, min_clean_3prime_nt: 5}
    warning: {max_mismatches: 5, max_gaps: 1, min_clean_3prime_nt: 3}
  probe_site:
    critical: {max_mismatches: 3, max_gaps: 0, min_clean_3prime_nt: 0}
    warning: {max_mismatches: 5, max_gaps: 1, min_clean_3prime_nt: 0}
  probe_binds_if: critical         # site level the probe needs for an amplicon to be 'likely detected'
  severity:                        # verdict contribution of each finding: FAIL | WARN | INFO
    primer_site_critical: FAIL     # a critical primer site that is part of a predicted product
    primer_site_critical_no_product: WARN  # ... that forms no predicted product (no facing
                                   #   partner): off-target priming, not a product
    primer_site_warning: WARN
    probe_site_critical: INFO      # a probe site alone cannot make a product: the probe signals
                                   #   only inside one (see amplicon_*); advisor 2026-09-25
    amplicon_likely_detected: FAIL
    amplicon_not_detected: WARN
  eukaryote_taxids: [9606]         # organisms for which genomic-DNA hits matter to RNA assays
  # Partner scan: next to every off-target primer site that can prime and forms no product, the
  # sequence a product could span (max_amplicon_size) is fetched and the partner primers are
  # aligned in it; probes are re-aligned inside products without a probe site. A partner or
  # probe site BLAST did not report (score below the E-value cut-off) is still found. At most
  # this many fetches per run, partner windows first, then products (cached; beyond: the
  # result is INCOMPLETE); 0 switches the scan off.
  partner_scan_max_windows: 1000
```
