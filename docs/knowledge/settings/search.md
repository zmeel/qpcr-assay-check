# Defaults

Generated by `scripts/build_knowledge.py` from `default_config.yaml`; do not edit by hand.

Every value is a starting point, not an acceptance criterion: each laboratory reviews it within its own quality system. An assay file can override a value under `settings:`; a `--config` file overrides the defaults for every run.[^default-config]

```yaml
search:
  # Short-oligo BLAST settings (see docs/ARCHITECTURE.md for the NCBI documentation they follow).
  program: blastn
  database: core_nt
  word_size: 7
  expect: 1000
  filter: "F"                      # low-complexity filtering off
  reward: 1
  penalty: -3
  gap_open: 5                      # assumed valid with reward 1 / penalty -3 (smoke test checks)
  gap_extend: 2
  hitlist_size: 5000               # maximum via the URL API is unverified; the smoke test checks it
  result_format: JSON2_S
  max_taxids_per_search: 20        # conservative until the smoke test verifies the real limit
  max_searches_warn: 50            # NCBI asks for off-peak scheduling above this
  background_taxids: [9606]        # human; add your own background taxa
  target_tier: false               # also BLAST the intended target as a tier: a positive control
                                   #   (perfect hits per oligo) that the variant analysis makes
                                   #   redundant, since it assesses every record of the target;
                                   #   for a large target the slowest search of a run (influenza A,
                                   #   1.68 million records: 19 hours, 2026-10-20). Off since
                                   #   2026-10-23 (user decision).
  relevance:
    min_identical_bases: 14        # a hit with fewer identical bases is not a relevant off-target
```
