# Defaults

Generated by `scripts/build_knowledge.py` from `default_config.yaml`; do not edit by hand.

Every value is a starting point, not an acceptance criterion: each laboratory reviews it within its own quality system. An assay file can override a value under `settings:`; a `--config` file overrides the defaults for every run.[^default-config]

```yaml
reaction:
  # Conditions used for melting temperatures and structure calculations (primer3 conventions).
  na_mM: 50.0            # monovalent cations
  mg_mM: 3.0             # free Mg2+
  dntp_mM: 0.8
  primer_nM: 400.0
  probe_nM: 200.0
  annealing_temp_C: 60.0 # annealing/extension temperature of the cycling protocol
  tm_method: santalucia          # santalucia | breslauer
  salt_correction: santalucia    # santalucia | owczarzy | schildkraut
```
